# Kidney-disease-MLFlow-DVC

clone the repository

```bash
https://github.com/ravisurapati12/Kidney-disease-MLFlow-DVC.git
```

 ```bash
 py -3.9 -m venv .venv  
 ```

 ```bash
  .\.venv\Scripts\Activate.ps1 
```

```bash
python --version
```

```bash
python -m pip install -r requirements.txt
```
